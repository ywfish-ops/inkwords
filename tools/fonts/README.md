# 字体

`tools/generate_fonts.py` 用这两个开源字体生成点阵字库，字体文件不提交到仓库，下载后放在本目录：

| 文件 | 用途 | 来源 | 许可 |
|------|------|------|------|
| `DejaVuSansCondensed.ttf` | 英文、数字、音标 | [DejaVu Fonts 2.37](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37) | Bitstream Vera 许可（DejaVu 改动为公有领域） |
| `NotoSansCJKsc-Medium.otf` | 中文与符号 | [noto-cjk](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese) | SIL OFL 1.1 |
